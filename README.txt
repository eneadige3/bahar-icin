Bahar için doğum günü sayfası

Sayfayı açmak için index.html dosyasına çift tıklaman yeterli.

Sonradan değiştirmek istersen:
- Metinler index.html dosyasında
- Renkler ve tasarım style.css dosyasında
- Küçük etkileşimler script.js dosyasında

GitHub Pages'a atarken bu klasörün içindekileri (özellikle index.html) bir GitHub reposunun ana dizinine yüklemen yeterli olur.
